# Biology and electronics comparison

`biology-electronics-comparison.mp4` is a 12-second, muted presentation loop. It is an edited visual comparison, not a synchronized experiment or a comparison of physical dimensions or rates.

- Biology: Yichao Zhao's intracellular calcium oscillation recording in CaSR-HEK cells (`3_1.5mM_4X.avi`).
- Electronics: supplied crop `03_dense_CMOS_emission_crop.mp4`, from Dmitry Nedospasov's [Security of the IC Backside](https://media.ccc.de/v/30C3_-_5459_-__-_saal_1_-_201312282145_-_security_of_the_ic_backside_-_nedos), 30C3, 2013, approximately 31:00–31:06. The supplied file's copyright metadata identifies [CC BY 3.0 DE](https://creativecommons.org/licenses/by/3.0/de/) as the source license.

Edits: fixed crops, independent clip-wide contrast, a common false-color palette, isotropic spatial scaling, and independent retiming with linear frame interpolation. Electronic intensity deviations from a fixed per-pixel median are amplified by 1.8 to make existing fluctuations more visible. No signal events were added. The output uses all 61 biological source frames and all 145 electronic source frames, interpolated to 24 fps over 12 seconds. The original files are preserved outside the site repository.

The related paper [Simple photonic emission analysis of AES](https://doi.org/10.1007/s13389-013-0053-7), published in 2013, is background reading. This excerpt is credited to the conference talk and has not been verified as supplementary material for that paper.
